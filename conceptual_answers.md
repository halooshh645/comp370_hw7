2. What are the two primary challenges that necessitate sampling when collecting data?
Time and availability => collecting data from the entire population can be both very time consuming and at times not possible

Money => collecting data from entire population can also be very very expensive

3. Why are website owners more likely to be upset about collecting data using scrapers than using APIs?

Website owners are more likely to dislike web scraping because scrapers can generate excessive server traffic without providing much benefit to the website (unecessary load on their servers). Unlike scraping, APIs allow website owners to control which data is accessible, enforce rate limits (how many requests a client can make within a certain period of time), records attained per request,  and monitor usage. Scraping may also bypass intended access restrictions or reuse content in ways the owner does not authorize.
